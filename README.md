🌌 Nova Verse — README
🚀 About Nova Verse

Nova Verse is an all-in-one futuristic web application designed to bring AI, entertainment, education, productivity, health tools, sports, shopping, and Islamic resources together in one interactive platform.

Nova Verse is designed and owned by Abdullah Ateeq, a Grade 10 student, and was created as a competition-focused coding project.

✨ Main Features
🤖 Nova AI — Interactive AI assistant interface
🔎 Web Search — Search and explore information
🎮 Games — Gaming section with interactive experiences
🎬 Movies — Explore movies and search content
🎵 Songs — Music discovery and search
⚽ Sports — Sports information and activities
❤️ Health Tools — Useful health calculators and tools
📚 Education — Educational content and lesson progress
📖 Quran & Islam — Quran, Hadith, Tafsir, Seerah and Islamic resources
🛒 Shopping & Food — Shopping and food-related tools
🏆 Leaderboard — Competition and progress features
📊 Analytics — Activity and progress information
🗂️ Workspace — Personal productivity area
❤️ Favorites — Save important content
👤 My Profile — Personal profile area
⚙️ Settings — Customize the application
📩 Contact Us — Contact section
🌟 About Nova — Information about the project and creator

The project is designed to run directly in a modern web browser without requiring a complex project structure.

▶️ How to Run
Download or save the HTML file.
Open the file in a modern browser such as Chrome or Edge.
Wait for the Nova Verse startup screen.
The Home dashboard will open.
Use the sidebar to explore the different sections.
